cron -h

cron 式の例

よく使われる crontab のスケジュールと、その実際の意味です。選択するとインタプリタで開きます。

式 意味
* * * * * 毎分
*/5 * * * * 5分ごと
*/10 * * * * 10分ごと
*/15 * * * * 15分ごと
*/20 * * * * 20分ごと
*/30 * * * * 30分ごと
0 * * * * 毎時0分
30 * * * * 毎時30分
0 */2 * * * 2時間ごと
0 */3 * * * 3時間ごと
0 */4 * * * 4時間ごと
0 */6 * * * 6時間ごと
0 */8 * * * 8時間ごと
0 */12 * * * 12時間ごと
0 9-17 * * * 9:00から17:00まで毎時
30 9-17 * * MON-FRI 9:30から17:30まで毎時、平日
*/15 */2 * * * 15分ごと、偶数時のみ
*/15 9-17 * * * 9:00から17:45まで15分ごと
0 0 * * * 毎日0:00
0 6 * * * 毎日6:00
0 9 * * * 毎日9:00
0 12 * * * 毎日12:00
0 18 * * * 毎日18:00
30 23 * * * 毎日23:30
0 0 * * 0 毎週日曜日の0:00
0 3 * * 0 毎週日曜日の3:00
0 9 * * MON-FRI 平日の9:00
30 8 * * SAT,SUN 週末の8:30
0 22 * * 1-5 平日の22:00
0 3 * * 1,3,5 毎週月曜日、水曜日、金曜日の3:00
0 0 1 * * 毎月1日の0:00
0 0 15 * * 毎月15日の0:00
15 14 1 * * 毎月1日の14:15
0 0 1 1 * 毎年1月1日の0:00
0 0 1,15 * * 毎月1日、15日の0:00
5 0 * 8 * 8月の毎日0:05
0 0 13 * FRI 毎月13日の0:00、および毎週金曜日の0:00。cron はどちらか一方が一致した時点で実行され、両方が揃う必要はありません
*/7 * * * * 毎時0分から56分まで7分ごと、その後は正時に再開
0 */5 * * * 毎日0:00から20:00まで5時間ごと、その後は翌日に再開
5-59/15 * * * * 15分ごと（毎時5分から）
@reboot システム起動時に1回
@hourly 毎時0分
@daily 毎日0:00
@weekly 毎週日曜日の0:00
@monthly 毎月1日の0:00
@yearly 毎年1月1日の0:00

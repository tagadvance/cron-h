cron -h

Примеры выражений cron

Часто встречающиеся расписания crontab и что они значат на самом деле. Выберите любое, чтобы открыть его в интерпретаторе.

Выражение Значение
* * * * * Каждую минуту
*/5 * * * * Каждые 5 минут
*/10 * * * * Каждые 10 минут
*/15 * * * * Каждые 15 минут
*/20 * * * * Каждые 20 минут
*/30 * * * * Каждые 30 минут
0 * * * * Каждый час, ровно в начале часа
30 * * * * Каждый час, на 30-й минуте
0 */2 * * * Каждые 2 часа
0 */3 * * * Каждые 3 часа
0 */4 * * * Каждые 4 часа
0 */6 * * * Каждые 6 часов
0 */8 * * * Каждые 8 часов
0 */12 * * * Каждые 12 часов
0 9-17 * * * Каждый час с 9:00 до 17:00
30 9-17 * * MON-FRI Каждый час с 9:30 до 17:30, по будням
*/15 */2 * * * Каждые 15 минут, в чётные часы
*/15 9-17 * * * Каждые 15 минут с 9:00 до 17:45
0 0 * * * Каждый день в 0:00
0 6 * * * Каждый день в 6:00
0 9 * * * Каждый день в 9:00
0 12 * * * Каждый день в 12:00
0 18 * * * Каждый день в 18:00
30 23 * * * Каждый день в 23:30
0 0 * * 0 По воскресеньям в 0:00
0 3 * * 0 По воскресеньям в 3:00
0 9 * * MON-FRI По будням в 9:00
30 8 * * SAT,SUN По выходным в 8:30
0 22 * * 1-5 По будням в 22:00
0 3 * * 1,3,5 По понедельникам, средам и пятницам в 3:00
0 0 1 * * Каждый месяц 1-го числа в 0:00
0 0 15 * * Каждый месяц 15-го числа в 0:00
15 14 1 * * Каждый месяц 1-го числа в 14:15
0 0 1 1 * Каждый год 1 января в 0:00
0 0 1,15 * * Каждый месяц 1-го и 15-го числа в 0:00
5 0 * 8 * В августе каждый день в 0:05
0 0 13 * FRI Каждый месяц 13-го числа в 0:00, а также по пятницам в 0:00: cron запускается, когда выполняется любое из двух условий, а не только когда оба сразу
*/7 * * * * Каждые 7 минут с 0 по 56 минуту каждого часа, затем снова в начале часа
0 */5 * * * Каждые 5 часов с 0:00 до 20:00 каждый день, затем снова на следующий день
5-59/15 * * * * Каждые 15 минут, начиная с 5-й минуты
@reboot Один раз при запуске системы
@hourly Каждый час, ровно в начале часа
@daily Каждый день в 0:00
@weekly По воскресеньям в 0:00
@monthly Каждый месяц 1-го числа в 0:00
@yearly Каждый год 1 января в 0:00
